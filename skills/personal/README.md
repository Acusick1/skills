# Personal

Skills specific to this fork. Not part of upstream.

- [docs-gardening](./docs-gardening/SKILL.md): review or rewrite human-facing Markdown docs against the loaded documentation rules.
- [issue-to-pr](./issue-to-pr/SKILL.md): take one ready-for-agent issue to a reviewed, CI-green pull request, asking the user only for decisions no agent can settle (`autonomous` records them on the PR instead).
- [onboard-repo](./onboard-repo/SKILL.md): bring a repo onto the shared agent practices (AGENTS.md, docs/agents config, triage labels, project board, lint over prose) and open a PR.
